# Chimera Detection Outputs

This directory stores real-time detection logs, metric traces, and diagnostic summaries generated by **Chimera IDS**.

---

## Output Structure

When `python run.py detect --input <target>` is executed:
- A timestamped directory `outputs/<target>_YYYYMMDD_HHMMSS/` is automatically created.
- **`report/Report.md`**: Executive summary with flow statistics, attack distributions, and MITRE ATT&CK tactical classifications.
- **`predictions/`**: Partitioned flow records:
  - `benign_flows.json` (traffic cleared as legitimate)
  - `dos_flows.json` (traffic flagged by supervised XGBoost)
  - `anomaly_flows.json` (traffic flagged by unsupervised B-DAP/Kitsune)
- **`logs/technical_debug.log`**: Detailed execution and heuristic override trace.
