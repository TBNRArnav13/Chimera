# Chimera Technical Documentation Directory

This directory contains technical guides, operational manuals, and architecture schematics for the **Chimera Intrusion Detection System**.

---

## Documents Index

1. **`1_User_Manual.md`**:
   Complete end-user operational manual covering installation, quick start, execution modes (`train_kitsune`, `train_xgboost`, `train_all`, `detect`), input file handling, and output reporting.

2. **`2_Technical_Documentation.md`**:
   Deep technical architecture guide outlining data flow, normalization parameters, model pipelines, and system requirements.

3. **`3_XGBoost_Model_Documentation.md`**:
   Supervised classification design, tree hyperparameters, training protocols, and feature importance matrices.

4. **`4_Kitsune_Model_Documentation.md`**:
   B-DAP (Benign-Data Alignment Processor) autoencoder ensemble architecture, RMSE anomaly scoring, and thresholding mechanisms.

5. **`5_Hybrid_Engine_Documentation.md`**:
   Priority-ordered decision engine specifications, priority routing logic, and protocol-aware safe-broadcast heuristics.

6. **`Chimera_Architecture.drawio`**:
   System architecture diagram in editable Draw.io format.

7. **`Unified_DoS_DDoS_XGBoost_Kitsune_PRD.txt`**:
   Product Requirements Document (PRD) detailing system constraints, target throughputs, and operational thresholds.
